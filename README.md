# MediaPipeHolistic

Real-time computer vision project combining MediaPipe, YOLO and OpenCV.

## Features

- 🧠 YOLO object detection
- 🕺 MediaPipe human pose / holistic tracking
- 📷 Real-time camera processing
- ⚡ Real-time inference
- 🐍 Python-based AI pipeline

## Technologies

- Python
- OpenCV
- MediaPipe
- YOLO
- PyTorch

## Installation

git clone ...
cd MediaPipeHolistic

python -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt

## Usage

python main.py
